一、磁碟結構與存取

1.1 磁碟物理結構

傳統硬碟（HDD）由多個磁碟盤片組成，資料儲存在磁性表面上。

磁碟組成要素

  • 磁碟盤片（Platter）：實際儲存資料的磁性圓盤
  • 磁軌（Track）：盤片上的同心圓環
  • 磁區（Sector）：磁軌上的扇形區域，通常為 512 bytes 或 4096 bytes
  • 磁柱（Cylinder）：所有盤片上相同位置的磁軌集合
  • 讀寫頭（Read/Write Head）：負責讀取和寫入資料
  • 磁臂（Arm）：控制讀寫頭移動的機械臂
磁碟結構示意圖： 讀寫頭 ↓ ┌────┴────┐ │ │ ────┼─────────┼──── 磁軌 (Track) │ · │ │ · · │ 磁區 (Sector) │ · · │ │ · · │ │·───────·│ └─────────┘ 磁碟盤片 磁柱 (Cylinder)： 多個盤片上相同位置的磁軌 盤片 0: ═══════ 盤片 1: ═══════ ← 同一磁柱 盤片 2: ═══════

1.2 磁碟存取時間

讀取或寫入資料的總時間由三個部分組成：

存取時間組成

1. 尋道時間（Seek Time）：移動讀寫頭到目標磁軌所需的時間

  • 通常是最耗時的部分（3-12 ms）
  • 取決於移動的磁軌數

2. 旋轉延遲（Rotational Latency）：等待目標磁區旋轉到讀寫頭下方的時間

  • 平均為半圈的旋轉時間
  • 7200 RPM 硬碟：平均約 4.17 ms
  • 公式：60 / (RPM × 2) 秒

3. 傳輸時間（Transfer Time）：實際讀取或寫入資料的時間

  • 通常最短（< 1 ms）
  • 取決於資料大小和傳輸速率

總存取時間 = 尋道時間 + 旋轉延遲 + 傳輸時間

二、磁碟排程演算法

2.1 為什麼需要磁碟排程？

當多個 I/O 請求同時到達時，需要決定服務這些請求的順序。好的排程可以：

  • 減少尋道時間
  • 提高磁碟使用率
  • 降低平均等待時間
  • 確保公平性

2.2 FCFS（First-Come, First-Served）

按照請求到達的順序處理，最簡單但效能可能不佳。

FCFS 特性

優點：

  • 公平，不會造成飢餓
  • 實作簡單

缺點：

  • 可能導致大量的磁頭移動
  • 平均尋道時間可能很長

2.3 SSTF（Shortest Seek Time First）

選擇距離當前磁頭位置最近的請求。

SSTF 特性

優點：

  • 減少總尋道時間
  • 吞吐量較 FCFS 好

缺點：

  • 可能造成飢餓（邊緣磁軌的請求可能長時間得不到服務）
  • 不是最優解

2.4 SCAN（電梯演算法）

磁頭在磁碟上來回掃描，服務路徑上的所有請求。

SCAN 運作方式

  • 磁頭向一個方向移動，服務路徑上的所有請求
  • 到達磁碟末端後反向移動
  • 類似電梯的運作方式

優點：

  • 避免飢餓問題
  • 平均等待時間較穩定

缺點：

  • 剛服務過的磁軌附近的新請求需要等待較久

2.5 C-SCAN（Circular SCAN）

改良的 SCAN，磁頭只在一個方向服務請求。

C-SCAN 運作方式

  • 磁頭向一個方向移動並服務請求
  • 到達末端後，快速返回起點（不服務請求）
  • 再次從起點開始向同一方向移動

優點：

  • 等待時間更加均勻
  • 避免 SCAN 的不公平性

2.6 LOOK 和 C-LOOK

SCAN 和 C-SCAN 的改良版，磁頭不需要移動到磁碟末端。

LOOK / C-LOOK 特性

  • LOOK：到達該方向最遠的請求後立即反向
  • C-LOOK：到達該方向最遠的請求後返回該方向最近的請求
  • 比 SCAN/C-SCAN 更有效率

2.7 演算法比較

演算法 平均尋道時間 公平性 實作複雜度 適用情境
FCFS 差 最公平 簡單 負載輕時
SSTF 較好 可能飢餓 中等 一般負載
SCAN 好 好 中等 重負載
C-SCAN 好 更好 中等 重負載
LOOK 很好 好 稍複雜 現代系統
C-LOOK 很好 最好 稍複雜 現代系統

三、RAID 技術

3.1 RAID 概念

RAID（Redundant Array of Independent Disks）是一種將多個磁碟組合使用的技術，可以提高效能或可靠性。

3.2 常見 RAID 等級

RAID 0（Striping）

  • 資料分散儲存在多個磁碟上
  • 優點：讀寫效能最佳
  • 缺點：無容錯，一個磁碟故障就全部遺失
  • 最少磁碟數：2

RAID 1（Mirroring）

  • 資料完全複製到另一個磁碟
  • 優點：容錯能力強，讀取效能好
  • 缺點：可用容量只有 50%，寫入效能一般
  • 最少磁碟數：2

RAID 5（Striping with Parity）

  • 資料和同位檢查碼分散儲存
  • 優點：平衡效能和容錯
  • 缺點：寫入時需計算同位檢查碼
  • 可容忍一個磁碟故障
  • 最少磁碟數：3

RAID 10（1+0）

  • 先做 Mirror 再做 Stripe
  • 優點：兼具效能和可靠性
  • 缺點：成本高，可用容量 50%
  • 最少磁碟數：4

四、SSD 與傳統硬碟

4.1 SSD 特性

固態硬碟（SSD）使用快閃記憶體儲存資料，與傳統硬碟有顯著差異。

特性 HDD（傳統硬碟） SSD（固態硬碟）
存取時間 5-10 ms 0.1 ms
隨機 I/O 慢 快
循序 I/O 中等 很快
噪音 有 無
抗震動 差 好
功耗 較高 較低
壽命 機械磨損 寫入次數限制
成本 低 較高
SSD 的磁碟排程：

由於 SSD 沒有機械移動部件，傳統的磁碟排程演算法對 SSD 效果不大。SSD 更注重於：

  • 磨損平衡（Wear Leveling）
  • 垃圾回收（Garbage Collection）
  • TRIM 指令支援

五、I/O 系統架構

5.1 I/O 系統分層

I/O 系統分層架構： ┌──────────────────────────┐ │ 使用者行程層 │ ← 應用程式 I/O 呼叫 ├──────────────────────────┤ │ 核心 I/O 子系統 │ ← 緩衝、快取、排程 ├──────────────────────────┤ │ 裝置驅動程式 │ ← 裝置特定操作 ├──────────────────────────┤ │ 中斷處理程式 │ ← 處理 I/O 完成中斷 ├──────────────────────────┤ │ 硬體裝置控制器 │ ← DMA、裝置暫存器 └──────────────────────────┘

5.2 緩衝（Buffering）

在記憶體中暫存資料，協調裝置與行程間的速度差異。

緩衝的類型

  • 單一緩衝：一個緩衝區
  • 雙重緩衝：兩個緩衝區，一個讀一個寫
  • 循環緩衝：多個緩衝區形成環狀

5.3 快取（Caching）

將經常存取的資料保存在高速記憶體中。

  • 減少磁碟存取次數
  • 提高系統效能
  • 需要考慮一致性問題

5.4 DMA（Direct Memory Access）

允許 I/O 裝置直接存取記憶體，不需要 CPU 介入。

DMA 優勢

  • 減輕 CPU 負擔
  • 提高資料傳輸效率
  • 允許 CPU 並行執行其他任務

6.1 FCFS 磁碟排程

fcfs_disk_scheduling.c FCFS 磁碟排程模擬 
#include <stdio.h>
#include <stdlib.h>

int calculate_total_head_movement(int requests[], int n, int initial_head) {
    int total_movement = 0;
    int current_position = initial_head;
    
    printf("\n=== FCFS 磁碟排程 ===\n");
    printf("初始磁頭位置: %d\n\n", initial_head);
    printf("請求序列: ");
    for (int i = 0; i < n; i++) {
        printf("%d ", requests[i]);
    }
    printf("\n\n");
    
    printf("磁頭移動過程：\n");
    printf("位置\t移動距離\t累計距離\n");
    printf("------------------------------------\n");
    printf("%d\t-\t\t0\n", current_position);
    
    for (int i = 0; i < n; i++) {
        int movement = abs(requests[i] - current_position);
        total_movement += movement;
        current_position = requests[i];
        
        printf("%d\t%d\t\t%d\n", current_position, movement, total_movement);
    }
    
    return total_movement;
}

int main() {
    int requests[] = {98, 183, 37, 122, 14, 124, 65, 67};
    int n = sizeof(requests) / sizeof(requests[0]);
    int initial_head = 53;
    
    int total_movement = calculate_total_head_movement(requests, n, initial_head);
    
    printf("\n總磁頭移動距離: %d 個磁軌\n", total_movement);
    printf("平均尋道長度: %.2f 個磁軌\n", (float)total_movement / n);
    
    return 0;
}

6.2 SSTF 磁碟排程

sstf_disk_scheduling.c SSTF 最短尋道時間優先 
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

#define MAX_REQUESTS 100

int find_closest(int requests[], bool serviced[], int n, int current) {
    int min_distance = 999999;
    int closest_index = -1;
    
    for (int i = 0; i < n; i++) {
        if (!serviced[i]) {
            int distance = abs(requests[i] - current);
            if (distance < min_distance) {
                min_distance = distance;
                closest_index = i;
            }
        }
    }
    
    return closest_index;
}

int sstf_scheduling(int requests[], int n, int initial_head) {
    bool serviced[MAX_REQUESTS] = {false};
    int total_movement = 0;
    int current_position = initial_head;
    
    printf("\n=== SSTF 磁碟排程 ===\n");
    printf("初始磁頭位置: %d\n\n", initial_head);
    
    printf("磁頭移動過程：\n");
    printf("步驟\t目標位置\t移動距離\t累計距離\n");
    printf("------------------------------------------------\n");
    printf("0\t%d\t\t-\t\t0\n", current_position);
    
    for (int step = 0; step < n; step++) {
        int next_index = find_closest(requests, serviced, n, current_position);
        
        if (next_index == -1) break;
        
        serviced[next_index] = true;
        int movement = abs(requests[next_index] - current_position);
        total_movement += movement;
        current_position = requests[next_index];
        
        printf("%d\t%d\t\t%d\t\t%d\n", 
               step + 1, current_position, movement, total_movement);
    }
    
    return total_movement;
}

int main() {
    int requests[] = {98, 183, 37, 122, 14, 124, 65, 67};
    int n = sizeof(requests) / sizeof(requests[0]);
    int initial_head = 53;
    
    int total_movement = sstf_scheduling(requests, n, initial_head);
    
    printf("\n總磁頭移動距離: %d 個磁軌\n", total_movement);
    printf("平均尋道長度: %.2f 個磁軌\n", (float)total_movement / n);
    
    return 0;
}

6.3 SCAN 磁碟排程

scan_disk_scheduling.c SCAN 電梯演算法 
#include <stdio.h>
#include <stdlib.h>

#define DISK_SIZE 200

int compare(const void* a, const void* b) {
    return (*(int*)a - *(int*)b);
}

int scan_scheduling(int requests[], int n, int initial_head, int direction) {
    int total_movement = 0;
    int current_position = initial_head;
    
    // 排序請求
    qsort(requests, n, sizeof(int), compare);
    
    printf("\n=== SCAN 磁碟排程 ===\n");
    printf("初始磁頭位置: %d\n", initial_head);
    printf("初始方向: %s\n\n", direction == 1 ? "往高磁軌" : "往低磁軌");
    
    // 找出當前位置的分界點
    int split = 0;
    for (int i = 0; i < n; i++) {
        if (requests[i] >= initial_head) {
            split = i;
            break;
        }
    }
    
    printf("磁頭移動順序: %d", current_position);
    
    if (direction == 1) {
        // 向上掃描
        for (int i = split; i < n; i++) {
            total_movement += abs(requests[i] - current_position);
            current_position = requests[i];
            printf(" -> %d", current_position);
        }
        
        // 到達最高點
        if (current_position != DISK_SIZE - 1) {
            total_movement += abs((DISK_SIZE - 1) - current_position);
            current_position = DISK_SIZE - 1;
            printf(" -> %d", current_position);
        }
        
        // 向下掃描
        for (int i = split - 1; i >= 0; i--) {
            total_movement += abs(requests[i] - current_position);
            current_position = requests[i];
            printf(" -> %d", current_position);
        }
    } else {
        // 向下掃描
        for (int i = split - 1; i >= 0; i--) {
            total_movement += abs(requests[i] - current_position);
            current_position = requests[i];
            printf(" -> %d", current_position);
        }
        
        // 到達最低點
        if (current_position != 0) {
            total_movement += abs(0 - current_position);
            current_position = 0;
            printf(" -> %d", current_position);
        }
        
        // 向上掃描
        for (int i = split; i < n; i++) {
            total_movement += abs(requests[i] - current_position);
            current_position = requests[i];
            printf(" -> %d", current_position);
        }
    }
    
    printf("\n");
    
    return total_movement;
}

int main() {
    int requests[] = {98, 183, 37, 122, 14, 124, 65, 67};
    int n = sizeof(requests) / sizeof(requests[0]);
    int initial_head = 53;
    int direction = 1; // 1 = 向上, 0 = 向下
    
    int total_movement = scan_scheduling(requests, n, initial_head, direction);
    
    printf("\n總磁頭移動距離: %d 個磁軌\n", total_movement);
    printf("平均尋道長度: %.2f 個磁軌\n", (float)total_movement / n);
    
    return 0;
}

6.4 C-SCAN 磁碟排程

cscan_disk_scheduling.c C-SCAN 循環掃描 
#include <stdio.h>
#include <stdlib.h>

#define DISK_SIZE 200

int compare(const void* a, const void* b) {
    return (*(int*)a - *(int*)b);
}

int cscan_scheduling(int requests[], int n, int initial_head) {
    int total_movement = 0;
    int current_position = initial_head;
    
    qsort(requests, n, sizeof(int), compare);
    
    printf("\n=== C-SCAN 磁碟排程 ===\n");
    printf("初始磁頭位置: %d\n\n", initial_head);
    
    int split = 0;
    for (int i = 0; i < n; i++) {
        if (requests[i] >= initial_head) {
            split = i;
            break;
        }
    }
    
    printf("磁頭移動順序: %d", current_position);
    
    // 向上掃描到末端
    for (int i = split; i < n; i++) {
        total_movement += abs(requests[i] - current_position);
        current_position = requests[i];
        printf(" -> %d", current_position);
    }
    
    // 到達最高點
    if (current_position != DISK_SIZE - 1) {
        total_movement += abs((DISK_SIZE - 1) - current_position);
        current_position = DISK_SIZE - 1;
        printf(" -> %d", current_position);
    }
    
    // 返回起點（不服務請求）
    total_movement += current_position; // 返回到 0
    current_position = 0;
    printf(" -> %d (返回)", current_position);
    
    // 從起點開始向上掃描
    for (int i = 0; i < split; i++) {
        total_movement += abs(requests[i] - current_position);
        current_position = requests[i];
        printf(" -> %d", current_position);
    }
    
    printf("\n");
    
    return total_movement;
}

int main() {
    int requests[] = {98, 183, 37, 122, 14, 124, 65, 67};
    int n = sizeof(requests) / sizeof(requests[0]);
    int initial_head = 53;
    
    int total_movement = cscan_scheduling(requests, n, initial_head);
    
    printf("\n總磁頭移動距離: %d 個磁軌\n", total_movement);
    printf("平均尋道長度: %.2f 個磁軌\n", (float)total_movement / n);
    
    return 0;
}

7. 問答題：說明 C-SCAN 相比 SCAN 的改進之處

參考答案：C-SCAN 改進了 SCAN 的不公平性問題。在 SCAN 中，剛被服務過的磁軌附近如果有新請求到達，需要等待磁頭反向回來才能被服務。C-SCAN 則讓磁頭只在一個方向服務請求，到達末端後快速返回起點（不服務請求），再從同一方向開始服務。這樣所有請求的等待時間更加均勻，提供了更一致的服務品質。

8. 問答題：解釋 DMA 如何提高 I/O 效能

參考答案：DMA（Direct Memory Access）允許 I/O 裝置直接存取記憶體，不需要 CPU 介入每一筆資料的傳輸。傳統方式中，CPU 需要負責將資料從 I/O 裝置搬移到記憶體，這會佔用大量 CPU 時間。使用 DMA 後，CPU 只需設定傳輸參數（起始位址、資料量等），由 DMA 控制器完成實際的資料傳輸，完成後以中斷通知 CPU。這樣 CPU 可以並行執行其他任務，大幅提高系統整體效能。
