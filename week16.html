一、專案選項

選擇一個你最感興趣且能充分展現所學知識的專案。每個專案都有不同的難度和技術重點。

專案 1：迷你作業系統模擬器 🖥️

難度：⭐⭐⭐⭐⭐ 困難

專案描述：

建立一個完整的作業系統模擬器，整合行程管理、記憶體管理、檔案系統等核心功能。

核心功能：

  • 行程管理：建立、排程、終止行程
  • CPU 排程：實作多種排程演算法（FCFS、SJF、Round Robin、Priority）
  • 記憶體管理：分頁、分段、虛擬記憶體
  • 檔案系統：檔案 CRUD、目錄管理、權限控制
  • 同步機制：Mutex、Semaphore、死結處理
  • Shell 介面：互動式命令列

加分功能：

  • 圖形化介面（GUI）
  • 效能監控儀表板
  • 支援多執行緒
  • 實作 I/O 排程

技術棧：C/C++, Python (GUI)

專案 2：分散式任務排程系統 🌐

難度：⭐⭐⭐⭐ 中高

專案描述：

建立一個分散式系統，可以將計算任務分配到多個節點執行。

核心功能：

  • 主節點（Master）：接收任務、分配工作、收集結果
  • 工作節點（Worker）：執行計算任務
  • 任務佇列：支援優先權排程
  • 負載平衡：動態分配任務
  • 容錯機制：節點失效處理
  • Web 儀表板：監控系統狀態

範例應用：

  • 分散式質數搜尋
  • 影像處理（批次縮放、濾鏡）
  • 蒙地卡羅模擬
  • 資料分析任務

技術棧：Python/Node.js, Docker, Socket, REST API

專案 3：容器化微服務平台 🐳

難度：⭐⭐⭐⭐ 中高

專案描述：

建立一個完整的微服務應用，展現雲端原生技術。

核心功能：

  • 至少 4 個微服務（如：用戶、訂單、商品、通知）
  • API Gateway：統一入口
  • 服務發現與註冊
  • 負載平衡
  • 資料庫（每個服務獨立 DB）
  • Docker Compose / Kubernetes 部署

進階功能：

  • CI/CD Pipeline
  • 日誌收集與監控（ELK/Prometheus）
  • 分散式追蹤
  • 自動擴展

技術棧：Docker, Kubernetes, Python/Node.js/Go

專案 4：高效能多執行緒伺服器 ⚡

難度：⭐⭐⭐⭐ 中高

專案描述：

實作一個高效能的網路伺服器，處理大量並行連線。

核心功能：

  • HTTP 伺服器：支援 GET、POST、PUT、DELETE
  • 執行緒池：高效處理並行請求
  • 連線管理：Keep-Alive、Timeout
  • 靜態檔案服務
  • 動態內容生成（CGI 或內建）
  • 日誌系統

進階功能：

  • SSL/TLS 支援
  • WebSocket 支援
  • 快取機制
  • 壓縮（gzip）
  • 效能測試與優化

技術棧：C/C++, POSIX Threads, epoll/kqueue

專案 5：系統監控與管理平台 📊

難度：⭐⭐⭐ 中等

專案描述：

建立一個完整的系統監控工具，收集、分析、視覺化系統資源。

核心功能：

  • 資源監控：CPU、記憶體、磁碟、網路
  • 行程管理：查看、終止、優先權調整
  • 歷史資料記錄
  • 即時圖表：折線圖、儀表板
  • 告警系統：閾值通知
  • Web 介面：響應式設計

進階功能：

  • 多主機監控
  • 日誌分析
  • 效能剖析工具
  • 自動化建議

技術棧：Python, Flask/Django, JavaScript, Chart.js

專案 6：虛擬檔案系統 📁

難度：⭐⭐⭐⭐ 中高

專案描述：

實作一個完整的檔案系統，支援檔案 CRUD、目錄、權限等。

核心功能：

  • 檔案操作：建立、讀取、寫入、刪除、重新命名
  • 目錄管理：樹狀結構、路徑解析
  • 檔案配置：實作索引配置或鏈結配置
  • 權限控制：rwx 權限系統
  • 元資料管理：檔案大小、時間戳記
  • 磁碟空間管理：bitmap 或 free list

進階功能：

  • 檔案快取
  • 日誌系統（Journaling）
  • 碎片整理
  • 壓縮支援
  • FUSE 整合（掛載為真實檔案系統）

技術棧：C/C++, FUSE (optional)

專案 7：記憶體管理模擬器 🧠

難度：⭐⭐⭐ 中等

專案描述：

實作完整的記憶體管理系統，包含分頁、分段、虛擬記憶體。

核心功能：

  • 記憶體配置演算法：First Fit、Best Fit、Worst Fit
  • 分頁系統：頁表、TLB 模擬
  • 虛擬記憶體：需求分頁
  • 頁面置換：FIFO、LRU、Optimal
  • 碎片分析
  • 視覺化記憶體狀態

進階功能：

  • 多層頁表
  • Working Set 分析
  • Thrashing 偵測
  • 效能比較工具

技術棧：C/Python, GUI (Tkinter/Qt)

專案 8：簡易容器引擎 🏗️

難度：⭐⭐⭐⭐⭐ 困難

專案描述：

使用 Linux Namespace 和 Cgroups 實作簡易容器引擎。

核心功能：

  • 容器建立與執行
  • Namespace 隔離：PID、NET、MNT、UTS
  • Cgroups 資源限制：CPU、Memory
  • 檔案系統隔離（chroot）
  • 映像檔管理
  • 容器生命週期管理

進階功能：

  • 網路橋接
  • Volume 掛載
  • 容器日誌
  • 簡易 Dockerfile 支援

技術棧：C/Go, Linux Kernel API

2.2 開發建議

💡 成功秘訣

  • 從簡單開始：先實作核心功能，再逐步擴展
  • 持續測試：寫一點測一點，不要累積問題
  • 版本控制：使用 Git，頻繁 commit
  • 清晰命名：變數、函數名稱要有意義
  • 寫好註解：解釋複雜邏輯和設計決策
  • 模組化設計：功能分離，降低耦合
⚠️ 常見陷阱
  • 功能範圍過大，無法在時限內完成
  • 過度優化，忽略核心功能
  • 沒有測試，到最後才發現問題
  • 文件不完整，別人看不懂
  • 沒有備份，資料遺失

2.3 品質檢查清單

提交前檢查項目

  • 核心功能完整運作
  • 沒有明顯的 bug
  • 程式碼有適當的註解
  • README 包含安裝和使用說明
  • 有測試案例或測試腳本
  • 錯誤處理完善
  • 記憶體沒有洩漏
  • 程式碼風格一致
  • 專案結構清晰
  • 有 Demo 展示
