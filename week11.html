一、作業系統安全基礎

1.1 安全的目標（CIA Triad）

資訊安全的三大核心目標：

CIA 三要素

  • 機密性（Confidentiality）：確保資訊只能被授權的使用者存取
    • 防止未授權的資訊洩漏
    • 使用加密技術保護資料
  • 完整性（Integrity）：確保資訊不被未授權修改
    • 防止資料被竄改
    • 使用雜湊函數驗證資料
  • 可用性（Availability）：確保授權使用者可以存取資源
    • 防止服務中斷
    • 抵禦阻斷服務攻擊（DoS）

1.2 安全威脅類型

常見安全威脅

  • 惡意軟體（Malware）：
    • 病毒（Virus）：附著在其他程式上
    • 蠕蟲（Worm）：自我複製並傳播
    • 木馬（Trojan）：偽裝成合法程式
    • 勒索軟體（Ransomware）：加密檔案並勒索
  • 未授權存取：
    • 密碼破解
    • 社交工程
    • 權限提升攻擊
  • 阻斷服務攻擊（DoS/DDoS）：
    • 消耗系統資源
    • 使服務無法正常運作
  • 資料洩露：
    • 緩衝區溢位攻擊
    • SQL 注入
    • 跨站腳本攻擊（XSS）

二、認證與授權

2.1 認證（Authentication）

驗證使用者身份的過程，確認「你是誰」。

認證方法

  • 知識因素（Something You Know）：
    • 密碼（Password）
    • PIN 碼
    • 安全問題
  • 擁有因素（Something You Have）：
    • 智慧卡
    • 手機（OTP）
    • 硬體金鑰
  • 生物特徵（Something You Are）：
    • 指紋
    • 虹膜掃描
    • 臉部辨識
  • 多因素認證（MFA）：結合兩個或以上的認證方法

2.2 密碼安全

密碼儲存的安全實務
  • 絕對不要以明文儲存密碼
  • 使用強雜湊函數（如 bcrypt、Argon2）
  • 加入鹽值（Salt）防止彩虹表攻擊
  • 使用多輪雜湊增加破解難度

2.3 授權（Authorization）

決定已認證的使用者可以做什麼，確認「你能做什麼」。

三、存取控制

3.1 存取控制模型

自主存取控制（DAC - Discretionary Access Control）

DAC 特性

  • 資源的擁有者決定誰可以存取
  • 使用者可以將權限授予其他使用者
  • 靈活但可能不安全
  • 範例：Unix/Linux 檔案權限

強制存取控制（MAC - Mandatory Access Control）

MAC 特性

  • 系統強制執行的存取控制策略
  • 使用者無法更改安全標籤
  • 更安全但較不靈活
  • 範例：SELinux、AppArmor

角色基礎存取控制（RBAC - Role-Based Access Control）

RBAC 特性

  • 根據使用者的角色授予權限
  • 簡化權限管理
  • 適合大型組織
  • 範例：管理員、一般使用者、訪客

3.2 存取控制列表（ACL）

為每個資源維護一份允許存取的使用者清單。

ACL 範例： 檔案: project.txt ACL: 使用者 Alice: 讀、寫、執行 使用者 Bob: 讀、寫 群組 developers: 讀 其他: 無權限

3.3 Linux/Unix 檔案權限

權限系統

Linux 使用 9 位元的權限系統：

  • 擁有者（Owner）權限：rwx（讀、寫、執行）
  • 群組（Group）權限：rwx
  • 其他人（Others）權限：rwx
權限表示法： -rwxr-xr-- │││││││││ │││││││└└─ 其他人權限: r-- (讀) ││││││└──── 群組權限: r-x (讀、執行) │││└└└────── 擁有者權限: rwx (讀、寫、執行) │└────────── 檔案類型: - (普通檔案) d (目錄) l (符號連結) 數字表示法： r = 4, w = 2, x = 1 rwxr-xr-- = 754 7 = rwx (4+2+1) 5 = r-x (4+0+1) 4 = r-- (4+0+0)

3.4 特殊權限

權限 符號 數字 說明
SUID s (在擁有者 x 位置) 4000 以檔案擁有者權限執行
SGID s (在群組 x 位置) 2000 以群組權限執行或繼承群組
Sticky Bit t (在其他人 x 位置) 1000 只有擁有者可刪除檔案

四、加密技術基礎

4.1 對稱式加密

使用相同的金鑰進行加密和解密。

對稱式加密特性

  • 優點：
    • 速度快
    • 適合大量資料
  • 缺點：
    • 金鑰分發問題
    • 需要安全的通道交換金鑰
  • 常見演算法：AES、DES、3DES、Blowfish

4.2 非對稱式加密

使用一對金鑰：公鑰（Public Key）和私鑰（Private Key）。

非對稱式加密特性

  • 運作方式：
    • 公鑰加密，私鑰解密（保密）
    • 私鑰加密，公鑰解密（數位簽章）
  • 優點：
    • 解決金鑰分發問題
    • 支援數位簽章
  • 缺點：
    • 速度較慢
    • 計算量大
  • 常見演算法：RSA、ECC、DSA

4.3 雜湊函數

將任意長度的資料轉換成固定長度的輸出。

雜湊函數特性

  • 單向性：無法從雜湊值反推原始資料
  • 確定性：相同輸入產生相同輸出
  • 抗碰撞：很難找到兩個不同輸入產生相同雜湊值
  • 雪崩效應：輸入小改變，輸出大幅改變
  • 常見演算法：SHA-256、SHA-3、bcrypt

4.4 數位簽章

用於驗證資料完整性和來源真實性。

數位簽章流程： 簽署方（Alice）: 1. 計算訊息雜湊值 2. 用私鑰加密雜湊值 → 數位簽章 3. 傳送訊息 + 簽章 驗證方（Bob）: 1. 計算收到訊息的雜湊值 2. 用 Alice 的公鑰解密簽章 3. 比對兩個雜湊值 4. 相同 → 驗證成功

5.1 簡易使用者認證系統

user_authentication.c 使用者登入系統（含密碼雜湊） 
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAX_USERS 100
#define MAX_NAME_LEN 50
#define MAX_PASS_LEN 100

typedef struct {
    char username[MAX_NAME_LEN];
    char password_hash[MAX_PASS_LEN];
    int is_active;
} User;

User users[MAX_USERS];
int user_count = 0;

// 簡單的雜湊函數（實際應用請使用 bcrypt 或 Argon2）
unsigned long simple_hash(const char* str) {
    unsigned long hash = 5381;
    int c;
    
    while ((c = *str++)) {
        hash = ((hash << 5) + hash) + c; // hash * 33 + c
    }
    
    return hash;
}

int register_user(const char* username, const char* password) {
    if (user_count >= MAX_USERS) {
        printf("使用者數量已達上限\n");
        return 0;
    }
    
    // 檢查使用者名稱是否已存在
    for (int i = 0; i < user_count; i++) {
        if (strcmp(users[i].username, username) == 0) {
            printf("使用者名稱已存在\n");
            return 0;
        }
    }
    
    // 註冊新使用者
    strcpy(users[user_count].username, username);
    sprintf(users[user_count].password_hash, "%lu", simple_hash(password));
    users[user_count].is_active = 1;
    user_count++;
    
    printf("✓ 使用者 '%s' 註冊成功\n", username);
    return 1;
}

int authenticate(const char* username, const char* password) {
    char hash[MAX_PASS_LEN];
    sprintf(hash, "%lu", simple_hash(password));
    
    for (int i = 0; i < user_count; i++) {
        if (strcmp(users[i].username, username) == 0 && users[i].is_active) {
            if (strcmp(users[i].password_hash, hash) == 0) {
                return 1; // 認證成功
            }
        }
    }
    
    return 0; // 認證失敗
}

void login() {
    char username[MAX_NAME_LEN];
    char password[MAX_PASS_LEN];
    
    printf("\n=== 使用者登入 ===\n");
    printf("使用者名稱: ");
    scanf("%s", username);
    printf("密碼: ");
    scanf("%s", password);
    
    if (authenticate(username, password)) {
        printf("✓ 登入成功！歡迎，%s\n", username);
    } else {
        printf("✗ 登入失敗：使用者名稱或密碼錯誤\n");
    }
}

int main() {
    int choice;
    char username[MAX_NAME_LEN];
    char password[MAX_PASS_LEN];
    
    printf("=== 簡易認證系統 ===\n\n");
    
    // 預設建立一些測試帳號
    register_user("admin", "admin123");
    register_user("alice", "password1");
    register_user("bob", "password2");
    
    while (1) {
        printf("\n1. 註冊新使用者\n");
        printf("2. 登入\n");
        printf("3. 列出所有使用者\n");
        printf("4. 離開\n");
        printf("選擇: ");
        scanf("%d", &choice);
        
        switch (choice) {
            case 1:
                printf("新使用者名稱: ");
                scanf("%s", username);
                printf("密碼: ");
                scanf("%s", password);
                register_user(username, password);
                break;
            case 2:
                login();
                break;
            case 3:
                printf("\n已註冊使用者:\n");
                for (int i = 0; i < user_count; i++) {
                    printf("  - %s\n", users[i].username);
                }
                break;
            case 4:
                printf("再見！\n");
                return 0;
            default:
                printf("無效選擇\n");
        }
    }
    
    return 0;
}

5.2 檔案權限檢查

file_permissions.c 檔案權限檢查工具 
#include <stdio.h>
#include <sys/stat.h>
#include <pwd.h>
#include <grp.h>
#include <time.h>

void print_permissions(mode_t mode) {
    printf((S_ISDIR(mode)) ? "d" : "-");
    printf((mode & S_IRUSR) ? "r" : "-");
    printf((mode & S_IWUSR) ? "w" : "-");
    printf((mode & S_IXUSR) ? "x" : "-");
    printf((mode & S_IRGRP) ? "r" : "-");
    printf((mode & S_IWGRP) ? "w" : "-");
    printf((mode & S_IXGRP) ? "x" : "-");
    printf((mode & S_IROTH) ? "r" : "-");
    printf((mode & S_IWOTH) ? "w" : "-");
    printf((mode & S_IXOTH) ? "x" : "-");
}

void print_special_permissions(mode_t mode) {
    if (mode & S_ISUID) printf(" SUID");
    if (mode & S_ISGID) printf(" SGID");
    if (mode & S_ISVTX) printf(" Sticky");
}

void check_file_permissions(const char* filename) {
    struct stat file_stat;
    
    if (stat(filename, &file_stat) == -1) {
        perror("無法取得檔案資訊");
        return;
    }
    
    printf("\n=== 檔案資訊: %s ===\n\n", filename);
    
    // 檔案類型
    printf("類型: ");
    if (S_ISREG(file_stat.st_mode)) {
        printf("普通檔案\n");
    } else if (S_ISDIR(file_stat.st_mode)) {
        printf("目錄\n");
    } else if (S_ISLNK(file_stat.st_mode)) {
        printf("符號連結\n");
    } else {
        printf("其他\n");
    }
    
    // 權限
    printf("權限: ");
    print_permissions(file_stat.st_mode);
    print_special_permissions(file_stat.st_mode);
    printf("\n");
    
    // 八進位表示
    printf("八進位: %o\n", file_stat.st_mode & 0777);
    
    // 擁有者資訊
    struct passwd* pw = getpwuid(file_stat.st_uid);
    struct group* gr = getgrgid(file_stat.st_gid);
    printf("擁有者: %s (UID: %d)\n", pw ? pw->pw_name : "unknown", file_stat.st_uid);
    printf("群組: %s (GID: %d)\n", gr ? gr->gr_name : "unknown", file_stat.st_gid);
    
    // 大小
    printf("大小: %ld bytes\n", file_stat.st_size);
    
    // Inode
    printf("Inode: %lu\n", file_stat.st_ino);
    
    // 時間
    printf("最後存取: %s", ctime(&file_stat.st_atime));
    printf("最後修改: %s", ctime(&file_stat.st_mtime));
    printf("狀態變更: %s", ctime(&file_stat.st_ctime));
    
    // 權限檢查
    printf("\n當前使用者的權限:\n");
    if (file_stat.st_mode & S_IRUSR) printf("  ✓ 可讀\n");
    if (file_stat.st_mode & S_IWUSR) printf("  ✓ 可寫\n");
    if (file_stat.st_mode & S_IXUSR) printf("  ✓ 可執行\n");
}

int main(int argc, char* argv[]) {
    if (argc < 2) {
        printf("用法: %s <檔案名稱>\n", argv[0]);
        return 1;
    }
    
    check_file_permissions(argv[1]);
    
    return 0;
}

5.3 簡易加密程式

simple_encryption.c XOR 加密示範 
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

// XOR 加密/解密（對稱式）
void xor_encrypt_decrypt(char* data, const char* key, int data_len) {
    int key_len = strlen(key);
    
    for (int i = 0; i < data_len; i++) {
        data[i] ^= key[i % key_len];
    }
}

void print_hex(const char* data, int len) {
    for (int i = 0; i < len; i++) {
        printf("%02x ", (unsigned char)data[i]);
    }
    printf("\n");
}

int main() {
    char message[256];
    char key[256];
    char encrypted[256];
    char decrypted[256];
    
    printf("=== XOR 加密示範 ===\n\n");
    
    printf("請輸入訊息: ");
    fgets(message, sizeof(message), stdin);
    message[strcspn(message, "\n")] = 0; // 移除換行
    
    printf("請輸入金鑰: ");
    fgets(key, sizeof(key), stdin);
    key[strcspn(key, "\n")] = 0;
    
    int msg_len = strlen(message);
    
    // 加密
    strcpy(encrypted, message);
    xor_encrypt_decrypt(encrypted, key, msg_len);
    
    printf("\n原始訊息: %s\n", message);
    printf("加密後 (hex): ");
    print_hex(encrypted, msg_len);
    
    // 解密
    strcpy(decrypted, encrypted);
    xor_encrypt_decrypt(decrypted, key, msg_len);
    
    printf("解密後: %s\n", decrypted);
    
    // 驗證
    if (strcmp(message, decrypted) == 0) {
        printf("\n✓ 加解密成功！\n");
    } else {
        printf("\n✗ 加解密失敗！\n");
    }
    
    return 0;
}

5.4 密碼強度檢查

password_strength.c 密碼強度驗證工具 
#include <stdio.h>
#include <string.h>
#include <ctype.h>

typedef struct {
    int has_lower;
    int has_upper;
    int has_digit;
    int has_special;
    int length;
} PasswordAnalysis;

PasswordAnalysis analyze_password(const char* password) {
    PasswordAnalysis analysis = {0, 0, 0, 0, 0};
    
    analysis.length = strlen(password);
    
    for (int i = 0; i < analysis.length; i++) {
        if (islower(password[i])) analysis.has_lower = 1;
        else if (isupper(password[i])) analysis.has_upper = 1;
        else if (isdigit(password[i])) analysis.has_digit = 1;
        else analysis.has_special = 1;
    }
    
    return analysis;
}

int calculate_strength(PasswordAnalysis analysis) {
    int strength = 0;
    
    if (analysis.length >= 8) strength += 1;
    if (analysis.length >= 12) strength += 1;
    if (analysis.length >= 16) strength += 1;
    
    if (analysis.has_lower) strength += 1;
    if (analysis.has_upper) strength += 1;
    if (analysis.has_digit) strength += 1;
    if (analysis.has_special) strength += 2;
    
    return strength;
}

void print_strength_report(const char* password) {
    PasswordAnalysis analysis = analyze_password(password);
    int strength = calculate_strength(analysis);
    
    printf("\n=== 密碼強度分析 ===\n");
    printf("密碼長度: %d\n", analysis.length);
    printf("包含小寫字母: %s\n", analysis.has_lower ? "✓" : "✗");
    printf("包含大寫字母: %s\n", analysis.has_upper ? "✓" : "✗");
    printf("包含數字: %s\n", analysis.has_digit ? "✓" : "✗");
    printf("包含特殊符號: %s\n", analysis.has_special ? "✓" : "✗");
    
    printf("\n強度評分: %d/9\n", strength);
    
    if (strength <= 3) {
        printf("評級: ✗ 弱 (不建議使用)\n");
    } else if (strength <= 6) {
        printf("評級: ⚠ 中等 (建議加強)\n");
    } else {
        printf("評級: ✓ 強 (安全)\n");
    }
    
    // 建議
    printf("\n改進建議:\n");
    if (analysis.length < 12) {
        printf("  - 增加密碼長度至少 12 個字元\n");
    }
    if (!analysis.has_lower) {
        printf("  - 加入小寫字母\n");
    }
    if (!analysis.has_upper) {
        printf("  - 加入大寫字母\n");
    }
    if (!analysis.has_digit) {
        printf("  - 加入數字\n");
    }
    if (!analysis.has_special) {
        printf("  - 加入特殊符號 (!@#$%%^&* 等)\n");
    }
}

int main() {
    char password[256];
    
    printf("=== 密碼強度檢查工具 ===\n\n");
    
    while (1) {
        printf("請輸入密碼 (輸入 'quit' 離開): ");
        fgets(password, sizeof(password), stdin);
        password[strcspn(password, "\n")] = 0;
        
        if (strcmp(password, "quit") == 0) {
            break;
        }
        
        print_strength_report(password);
        printf("\n");
    }
    
    printf("再見！\n");
    return 0;
}

5.5 存取控制列表（ACL）模擬

acl_simulation.c ACL 存取控制模擬 
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

#define MAX_USERS 50
#define MAX_RESOURCES 50
#define MAX_NAME 50

typedef enum {
    NONE = 0,
    READ = 1,
    WRITE = 2,
    EXECUTE = 4
} Permission;

typedef struct {
    char username[MAX_NAME];
    Permission permissions;
} ACLEntry;

typedef struct {
    char resource_name[MAX_NAME];
    ACLEntry entries[MAX_USERS];
    int entry_count;
} Resource;

Resource resources[MAX_RESOURCES];
int resource_count = 0;

void add_resource(const char* name) {
    strcpy(resources[resource_count].resource_name, name);
    resources[resource_count].entry_count = 0;
    resource_count++;
    printf("✓ 已建立資源: %s\n", name);
}

void grant_permission(const char* resource, const char* user, Permission perm) {
    for (int i = 0; i < resource_count; i++) {
        if (strcmp(resources[i].resource_name, resource) == 0) {
            // 檢查使用者是否已存在
            for (int j = 0; j < resources[i].entry_count; j++) {
                if (strcmp(resources[i].entries[j].username, user) == 0) {
                    resources[i].entries[j].permissions |= perm;
                    printf("✓ 已更新 %s 對 %s 的權限\n", user, resource);
                    return;
                }
            }
            
            // 新增使用者權限
            strcpy(resources[i].entries[resources[i].entry_count].username, user);
            resources[i].entries[resources[i].entry_count].permissions = perm;
            resources[i].entry_count++;
            printf("✓ 已授予 %s 對 %s 的權限\n", user, resource);
            return;
        }
    }
    printf("✗ 找不到資源: %s\n", resource);
}

int check_permission(const char* resource, const char* user, Permission perm) {
    for (int i = 0; i < resource_count; i++) {
        if (strcmp(resources[i].resource_name, resource) == 0) {
            for (int j = 0; j < resources[i].entry_count; j++) {
                if (strcmp(resources[i].entries[j].username, user) == 0) {
                    return (resources[i].entries[j].permissions & perm) == perm;
                }
            }
        }
    }
    return 0;
}

void list_acl(const char* resource) {
    for (int i = 0; i < resource_count; i++) {
        if (strcmp(resources[i].resource_name, resource) == 0) {
            printf("\n=== ACL for %s ===\n", resource);
            printf("使用者\t\t權限\n");
            printf("--------------------------------\n");
            
            for (int j = 0; j < resources[i].entry_count; j++) {
                printf("%s\t\t", resources[i].entries[j].username);
                
                Permission p = resources[i].entries[j].permissions;
                if (p & READ) printf("R");
                if (p & WRITE) printf("W");
                if (p & EXECUTE) printf("X");
                printf("\n");
            }
            return;
        }
    }
    printf("✗ 找不到資源: %s\n", resource);
}

int main() {
    printf("=== ACL 存取控制系統 ===\n\n");
    
    // 建立資源
    add_resource("project.txt");
    add_resource("database");
    add_resource("script.sh");
    
    // 授予權限
    grant_permission("project.txt", "alice", READ | WRITE);
    grant_permission("project.txt", "bob", READ);
    grant_permission("database", "alice", READ | WRITE | EXECUTE);
    grant_permission("script.sh", "charlie", READ | EXECUTE);
    
    // 列出 ACL
    list_acl("project.txt");
    list_acl("database");
    list_acl("script.sh");
    
    // 檢查權限
    printf("\n=== 權限檢查 ===\n");
    printf("Alice 可以寫入 project.txt? %s\n", 
           check_permission("project.txt", "alice", WRITE) ? "是" : "否");
    printf("Bob 可以寫入 project.txt? %s\n", 
           check_permission("project.txt", "bob", WRITE) ? "是" : "否");
    printf("Charlie 可以執行 script.sh? %s\n", 
           check_permission("script.sh", "charlie", EXECUTE) ? "是" : "否");
    
    return 0;
}

7. 問答題：說明多因素認證（MFA）的優勢

參考答案：多因素認證結合兩個或以上的認證方法（如密碼 + 手機驗證碼），大幅提高安全性。即使攻擊者取得其中一個因素（如密碼被盜），仍無法通過認證，因為還需要其他因素（如手機 OTP）。這種分層防禦可以有效防止帳號被盜用，是目前最佳的認證實務。常見組合包括：密碼 + OTP、密碼 + 生物辨識、智慧卡 + PIN 碼等。

8. 問答題：解釋為什麼密碼不應以明文儲存，以及正確的儲存方式

參考答案：密碼絕對不應以明文儲存，因為：(1) 資料庫若被入侵，所有密碼立即外洩；(2) 管理員或內部人員可以看到使用者密碼；(3) 違反隱私保護原則。正確做法是：使用強雜湊函數（如 bcrypt、Argon2）對密碼進行雜湊，並加入隨機鹽值（Salt）。鹽值可防止彩虹表攻擊。此外應使用多輪雜湊（如 bcrypt 預設 10 輪）增加破解難度。驗證時，將使用者輸入的密碼用相同方式雜湊後，與儲存的雜湊值比對。
