一、分散式系統基礎

1.1 什麼是分散式系統？

分散式系統是由多個獨立的電腦組成，透過網路互相通訊與協調，對使用者呈現為單一系統的電腦系統。

分散式系統的特性

  • 資源共享：硬體、軟體、資料可以被多個使用者共享
  • 透明性：使用者感覺不到系統是分散的
  • 並行性：多個節點可以同時執行任務
  • 可擴展性：可以增加節點來提升效能
  • 容錯性：部分節點故障不影響整體運作

1.2 分散式系統的優勢

  • 效能提升：工作可以分散到多台電腦處理
  • 資源共享：共用昂貴的硬體資源
  • 可靠性：透過備份提高系統可用性
  • 擴展性：可以逐步增加資源
  • 地理分散：服務可以接近使用者

1.3 分散式系統的挑戰

主要挑戰
  • 網路延遲：通訊需要時間
  • 部分失效：某些節點可能故障
  • 並行控制：多個節點同時存取資源
  • 一致性：保持資料一致性困難
  • 安全性：網路傳輸的安全問題
  • 時鐘同步：不同節點的時間可能不同步

Socket 是網路通訊的端點，提供程式與網路之間的介面。

TCP Socket 通訊流程： 伺服器端: 客戶端: socket() socket() ↓ ↓ bind() connect() ──┐ ↓ ↓ │ listen() (等待連線) │ ↓ ↓ │ accept() ←──────────────────────────────┘ ↓ ↓ read()/write() ←────────→ write()/read() ↓ ↓ close() close()

三、客戶端-伺服器架構

3.1 基本架構

客戶端-伺服器模型

  • 伺服器（Server）：
    • 提供服務
    • 持續運行等待請求
    • 處理多個客戶端
  • 客戶端（Client）：
    • 發起請求
    • 主動連線伺服器
    • 接收回應

3.2 伺服器類型

迭代伺服器（Iterative Server）

  • 一次處理一個客戶端請求
  • 簡單但效率低
  • 適合簡單、快速的服務

並行伺服器（Concurrent Server）

  • 同時處理多個客戶端
  • 使用多執行緒或多行程
  • 適合複雜、耗時的服務

3.3 多工 I/O

I/O 多工技術

  • select()：
    • 傳統的多工方式
    • 可監控多個檔案描述符
    • 效能限制（FD_SETSIZE）
  • poll()：
    • 改進的 select
    • 無描述符數量限制
    • 但仍需線性掃描
  • epoll()（Linux）：
    • 高效能的事件通知
    • 適合大量連線
    • O(1) 時間複雜度

四、遠端程序呼叫（RPC）

4.1 RPC 概念

RPC 讓程式可以呼叫另一台電腦上的函數，就像呼叫本地函數一樣。

RPC 運作流程： 客戶端 伺服器 │ │ ├─ 呼叫本地存根 │ │ (Client Stub) │ ├─ 封裝參數 │ │ (Marshalling) │ ├─ 透過網路傳送 ────────→ │ │ ├─ 接收請求 │ ├─ 解析參數 │ │ (Unmarshalling) │ ├─ 執行實際函數 │ ├─ 封裝結果 │ ←──────── 傳回結果 ────├ ├─ 解析結果 │ └─ 返回給呼叫者 │

4.2 分散式檔案系統

允許多台電腦透過網路共享檔案系統。

常見的分散式檔案系統

  • NFS（Network File System）：
    • Unix/Linux 常用
    • 透明的遠端檔案存取
  • CIFS/SMB：
    • Windows 檔案共享
    • 跨平台支援
  • HDFS（Hadoop）：
    • 大數據應用
    • 高吞吐量

5.1 TCP 伺服器

tcp_server.c 簡易 TCP 伺服器 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

#define PORT 8080
#define BUFFER_SIZE 1024

int main() {
    int server_fd, client_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t addr_len = sizeof(client_addr);
    char buffer[BUFFER_SIZE];
    
    // 建立 socket
    server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd == -1) {
        perror("Socket 建立失敗");
        exit(EXIT_FAILURE);
    }
    
    // 設定 socket 選項（允許重用位址）
    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    
    // 設定伺服器位址
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(PORT);
    
    // 綁定 socket
    if (bind(server_fd, (struct sockaddr*)&server_addr, sizeof(server_addr)) == -1) {
        perror("Bind 失敗");
        close(server_fd);
        exit(EXIT_FAILURE);
    }
    
    // 監聽連線
    if (listen(server_fd, 5) == -1) {
        perror("Listen 失敗");
        close(server_fd);
        exit(EXIT_FAILURE);
    }
    
    printf("伺服器正在 Port %d 監聽...\n", PORT);
    
    while (1) {
        // 接受連線
        client_fd = accept(server_fd, (struct sockaddr*)&client_addr, &addr_len);
        if (client_fd == -1) {
            perror("Accept 失敗");
            continue;
        }
        
        printf("收到來自 %s:%d 的連線\n", 
               inet_ntoa(client_addr.sin_addr), 
               ntohs(client_addr.sin_port));
        
        // 接收資料
        memset(buffer, 0, BUFFER_SIZE);
        int bytes_received = recv(client_fd, buffer, BUFFER_SIZE - 1, 0);
        
        if (bytes_received > 0) {
            printf("收到訊息: %s\n", buffer);
            
            // 回覆訊息
            const char* response = "訊息已收到！";
            send(client_fd, response, strlen(response), 0);
        }
        
        close(client_fd);
        printf("連線已關閉\n\n");
    }
    
    close(server_fd);
    return 0;
}

5.2 TCP 客戶端

tcp_client.c 簡易 TCP 客戶端 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

#define SERVER_IP "127.0.0.1"
#define PORT 8080
#define BUFFER_SIZE 1024

int main() {
    int sock_fd;
    struct sockaddr_in server_addr;
    char buffer[BUFFER_SIZE];
    char message[BUFFER_SIZE];
    
    // 建立 socket
    sock_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (sock_fd == -1) {
        perror("Socket 建立失敗");
        exit(EXIT_FAILURE);
    }
    
    // 設定伺服器位址
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_port = htons(PORT);
    
    if (inet_pton(AF_INET, SERVER_IP, &server_addr.sin_addr) <= 0) {
        perror("無效的位址");
        close(sock_fd);
        exit(EXIT_FAILURE);
    }
    
    // 連線到伺服器
    if (connect(sock_fd, (struct sockaddr*)&server_addr, sizeof(server_addr)) == -1) {
        perror("連線失敗");
        close(sock_fd);
        exit(EXIT_FAILURE);
    }
    
    printf("已連線到伺服器 %s:%d\n", SERVER_IP, PORT);
    
    // 輸入訊息
    printf("請輸入訊息: ");
    fgets(message, BUFFER_SIZE, stdin);
    message[strcspn(message, "\n")] = 0; // 移除換行
    
    // 傳送訊息
    send(sock_fd, message, strlen(message), 0);
    printf("訊息已傳送\n");
    
    // 接收回覆
    memset(buffer, 0, BUFFER_SIZE);
    int bytes_received = recv(sock_fd, buffer, BUFFER_SIZE - 1, 0);
    
    if (bytes_received > 0) {
        printf("伺服器回覆: %s\n", buffer);
    }
    
    close(sock_fd);
    return 0;
}

5.3 多執行緒伺服器

multithreaded_server.c 多執行緒 TCP 伺服器 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <pthread.h>
#include <arpa/inet.h>

#define PORT 8080
#define BUFFER_SIZE 1024
#define MAX_CLIENTS 10

int client_count = 0;
pthread_mutex_t count_mutex = PTHREAD_MUTEX_INITIALIZER;

typedef struct {
    int socket;
    struct sockaddr_in address;
    int id;
} client_info_t;

void* handle_client(void* arg) {
    client_info_t* client = (client_info_t*)arg;
    char buffer[BUFFER_SIZE];
    int bytes_received;
    
    printf("[Client %d] 連線來自 %s:%d\n", 
           client->id,
           inet_ntoa(client->address.sin_addr),
           ntohs(client->address.sin_port));
    
    // 歡迎訊息
    const char* welcome = "歡迎連線到多執行緒伺服器！\n";
    send(client->socket, welcome, strlen(welcome), 0);
    
    // 處理客戶端請求
    while ((bytes_received = recv(client->socket, buffer, BUFFER_SIZE - 1, 0)) > 0) {
        buffer[bytes_received] = '\0';
        
        printf("[Client %d] 收到: %s\n", client->id, buffer);
        
        // 檢查是否要離開
        if (strcmp(buffer, "quit") == 0) {
            const char* goodbye = "再見！\n";
            send(client->socket, goodbye, strlen(goodbye), 0);
            break;
        }
        
        // 回覆訊息
        char response[BUFFER_SIZE];
        snprintf(response, BUFFER_SIZE, "[伺服器] 已收到: %s\n", buffer);
        send(client->socket, response, strlen(response), 0);
        
        memset(buffer, 0, BUFFER_SIZE);
    }
    
    printf("[Client %d] 連線關閉\n", client->id);
    
    close(client->socket);
    
    pthread_mutex_lock(&count_mutex);
    client_count--;
    pthread_mutex_unlock(&count_mutex);
    
    free(client);
    pthread_detach(pthread_self());
    
    return NULL;
}

int main() {
    int server_fd, client_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t addr_len = sizeof(client_addr);
    pthread_t thread_id;
    
    // 建立 socket
    server_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (server_fd == -1) {
        perror("Socket 建立失敗");
        exit(EXIT_FAILURE);
    }
    
    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    
    // 設定伺服器位址
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(PORT);
    
    // 綁定與監聽
    if (bind(server_fd, (struct sockaddr*)&server_addr, sizeof(server_addr)) == -1) {
        perror("Bind 失敗");
        close(server_fd);
        exit(EXIT_FAILURE);
    }
    
    if (listen(server_fd, MAX_CLIENTS) == -1) {
        perror("Listen 失敗");
        close(server_fd);
        exit(EXIT_FAILURE);
    }
    
    printf("多執行緒伺服器正在 Port %d 監聽...\n", PORT);
    printf("最多支援 %d 個同時連線\n\n", MAX_CLIENTS);
    
    while (1) {
        client_fd = accept(server_fd, (struct sockaddr*)&client_addr, &addr_len);
        
        if (client_fd == -1) {
            perror("Accept 失敗");
            continue;
        }
        
        pthread_mutex_lock(&count_mutex);
        if (client_count >= MAX_CLIENTS) {
            pthread_mutex_unlock(&count_mutex);
            const char* msg = "伺服器已滿，請稍後再試\n";
            send(client_fd, msg, strlen(msg), 0);
            close(client_fd);
            continue;
        }
        client_count++;
        pthread_mutex_unlock(&count_mutex);
        
        // 建立客戶端資訊
        client_info_t* client = malloc(sizeof(client_info_t));
        client->socket = client_fd;
        client->address = client_addr;
        client->id = client_count;
        
        // 建立執行緒處理客戶端
        if (pthread_create(&thread_id, NULL, handle_client, (void*)client) != 0) {
            perror("執行緒建立失敗");
            free(client);
            close(client_fd);
            
            pthread_mutex_lock(&count_mutex);
            client_count--;
            pthread_mutex_unlock(&count_mutex);
        }
    }
    
    close(server_fd);
    return 0;
}

5.4 簡易聊天室伺服器

chat_server.c 多人聊天室伺服器 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <pthread.h>
#include <arpa/inet.h>

#define PORT 8080
#define BUFFER_SIZE 1024
#define MAX_CLIENTS 10

typedef struct {
    int socket;
    char name[50];
    int active;
} client_t;

client_t clients[MAX_CLIENTS];
int client_count = 0;
pthread_mutex_t clients_mutex = PTHREAD_MUTEX_INITIALIZER;

void broadcast_message(const char* message, int sender_socket) {
    pthread_mutex_lock(&clients_mutex);
    
    for (int i = 0; i < MAX_CLIENTS; i++) {
        if (clients[i].active && clients[i].socket != sender_socket) {
            send(clients[i].socket, message, strlen(message), 0);
        }
    }
    
    pthread_mutex_unlock(&clients_mutex);
}

void* handle_client(void* arg) {
    int client_socket = *(int*)arg;
    free(arg);
    
    char buffer[BUFFER_SIZE];
    char name[50];
    int client_index = -1;
    
    // 接收使用者名稱
    recv(client_socket, name, sizeof(name), 0);
    name[strcspn(name, "\n")] = 0;
    
    // 加入客戶端列表
    pthread_mutex_lock(&clients_mutex);
    for (int i = 0; i < MAX_CLIENTS; i++) {
        if (!clients[i].active) {
            clients[i].socket = client_socket;
            strcpy(clients[i].name, name);
            clients[i].active = 1;
            client_index = i;
            client_count++;
            break;
        }
    }
    pthread_mutex_unlock(&clients_mutex);
    
    if (client_index == -1) {
        const char* msg = "聊天室已滿\n";
        send(client_socket, msg, strlen(msg), 0);
        close(client_socket);
        return NULL;
    }
    
    printf("%s 加入聊天室\n", name);
    
    // 廣播加入訊息
    char join_msg[BUFFER_SIZE];
    snprintf(join_msg, BUFFER_SIZE, "*** %s 加入聊天室 ***\n", name);
    broadcast_message(join_msg, client_socket);
    
    // 接收訊息
    while (recv(client_socket, buffer, BUFFER_SIZE, 0) > 0) {
        buffer[strcspn(buffer, "\n")] = 0;
        
        if (strlen(buffer) > 0) {
            char message[BUFFER_SIZE];
            snprintf(message, BUFFER_SIZE, "[%s]: %s\n", name, buffer);
            printf("%s", message);
            broadcast_message(message, -1); // 廣播給所有人
        }
        
        memset(buffer, 0, BUFFER_SIZE);
    }
    
    // 客戶端離開
    pthread_mutex_lock(&clients_mutex);
    clients[client_index].active = 0;
    client_count--;
    pthread_mutex_unlock(&clients_mutex);
    
    printf("%s 離開聊天室\n", name);
    
    char leave_msg[BUFFER_SIZE];
    snprintf(leave_msg, BUFFER_SIZE, "*** %s 離開聊天室 ***\n", name);
    broadcast_message(leave_msg, -1);
    
    close(client_socket);
    pthread_detach(pthread_self());
    
    return NULL;
}

int main() {
    int server_fd, client_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t addr_len = sizeof(client_addr);
    pthread_t thread_id;
    
    // 初始化客戶端列表
    memset(clients, 0, sizeof(clients));
    
    server_fd = socket(AF_INET, SOCK_STREAM, 0);
    int opt = 1;
    setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(PORT);
    
    bind(server_fd, (struct sockaddr*)&server_addr, sizeof(server_addr));
    listen(server_fd, MAX_CLIENTS);
    
    printf("聊天室伺服器啟動於 Port %d\n", PORT);
    printf("等待客戶端連線...\n\n");
    
    while (1) {
        client_fd = accept(server_fd, (struct sockaddr*)&client_addr, &addr_len);
        
        if (client_fd == -1) {
            continue;
        }
        
        int* socket_ptr = malloc(sizeof(int));
        *socket_ptr = client_fd;
        
        pthread_create(&thread_id, NULL, handle_client, (void*)socket_ptr);
    }
    
    close(server_fd);
    return 0;
}

5.5 UDP 通訊範例

udp_server.c UDP 伺服器（無連線） 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <arpa/inet.h>

#define PORT 8080
#define BUFFER_SIZE 1024

int main() {
    int sock_fd;
    struct sockaddr_in server_addr, client_addr;
    socklen_t addr_len = sizeof(client_addr);
    char buffer[BUFFER_SIZE];
    
    // 建立 UDP socket
    sock_fd = socket(AF_INET, SOCK_DGRAM, 0);
    if (sock_fd == -1) {
        perror("Socket 建立失敗");
        exit(EXIT_FAILURE);
    }
    
    // 設定伺服器位址
    memset(&server_addr, 0, sizeof(server_addr));
    server_addr.sin_family = AF_INET;
    server_addr.sin_addr.s_addr = INADDR_ANY;
    server_addr.sin_port = htons(PORT);
    
    // 綁定
    if (bind(sock_fd, (struct sockaddr*)&server_addr, sizeof(server_addr)) == -1) {
        perror("Bind 失敗");
        close(sock_fd);
        exit(EXIT_FAILURE);
    }
    
    printf("UDP 伺服器正在 Port %d 監聽...\n", PORT);
    
    while (1) {
        memset(buffer, 0, BUFFER_SIZE);
        
        // 接收資料
        int bytes_received = recvfrom(sock_fd, buffer, BUFFER_SIZE - 1, 0,
                                     (struct sockaddr*)&client_addr, &addr_len);
        
        if (bytes_received > 0) {
            printf("收到來自 %s:%d 的訊息: %s\n",
                   inet_ntoa(client_addr.sin_addr),
                   ntohs(client_addr.sin_port),
                   buffer);
            
            // 回覆
            const char* response = "UDP 訊息已收到";
            sendto(sock_fd, response, strlen(response), 0,
                   (struct sockaddr*)&client_addr, addr_len);
        }
    }
    
    close(sock_fd);
    return 0;
}

7. 問答題：說明客戶端-伺服器架構的優缺點

參考答案：優點包括：(1) 集中管理資源和資料；(2) 容易維護和更新；(3) 安全性較好，可以集中控制存取；(4) 客戶端程式較簡單。缺點包括：(1) 伺服器是單點故障；(2) 伺服器可能成為效能瓶頸；(3) 擴展性受限於伺服器容量；(4) 網路依賴性高。適合需要集中管理的應用，如資料庫系統、Web 服務等。

8. 問答題：為什麼多執行緒伺服器優於迭代伺服器？並說明潛在問題

參考答案：多執行緒伺服器的優勢：(1) 可同時處理多個客戶端請求，提高並行度；(2) 單一客戶端的長時間操作不會阻塞其他客戶端；(3) 充分利用多核心 CPU。潛在問題：(1) 執行緒管理的額外開銷；(2) 需要處理執行緒同步問題；(3) 共享資源的競爭條件；(4) 執行緒數量過多會降低效能。解決方案包括使用執行緒池、適當的同步機制（mutex）、以及考慮使用 I/O 多工（如 epoll）作為替代方案。
